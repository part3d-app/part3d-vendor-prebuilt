# part3d-vendor-prebuilt

Prebuilt libraries used by [Part3D](https://github.com/part3d-app).

Download them from [Releases](https://github.com/part3d-app/part3d-vendor-prebuilt/releases).

## What's here

| Release tag | Contents |
| --- | --- |
| `occt-<version>-<commit>` | Our modified [Open CASCADE Technology](https://github.com/Open-Cascade-SAS/OCCT) (OCCT), plus Draco |
| `acs-<version>` | ACS sketch solver |

Each release lists the commit it was built from and the changes it contains.

## Platforms

- macOS (arm64)
- iOS (arm64, and arm64 simulator for ACS)
- Linux (arm64)
- Windows (x64)

Not every release has every platform. Check the assets on the release.
